# Initialise scripts 0.15.0
Run `bin/script.sh init scripts 0.15.0`. It copies `scripts/0.14.0` to `scripts/0.15.0` and sets `scripts=0.15.0` in `version`. Never edit `scripts/0.14.0` in place.

## Files to Change
- `scripts/0.15.0/` — new folder copied from `0.14.0`.
- `version` — `scripts=0.15.0`.
